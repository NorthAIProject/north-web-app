# Khepri brand — "A brighter you"

The identity since 2026-10-30. It is drawn from the reference image "Khepri: A
Brighter Future", which shows a winged solar emblem, a serif wordmark, the motto
and a robotic scarab companion. Navy armour with gold trim: intelligence and
warmth, not neon.

The web theme (`src/lib/styles/app.css`) is the only source of colour. iOS
generates its colour sets from it with `scripts/sync-theme.py` in north-ios-app.
Every logo file is generated by `scripts/brand/build.py`.

## Provenance — what is original and what is not

| Asset | Status |
|---|---|
| Emblem (`static/assets/brand/solar/khepri-emblem-*`) | **Vector interpretation** of the reference, drawn by hand in `scripts/brand/build.py`. Not a designer's source file. It keeps the reference's silhouette: two crescent wings, the sphere, the horizon dome, the pointed base, the stem and dot. |
| Wordmark | "Khepri" set in Marcellus (OFL) and converted to outlines. The dot of the i is replaced by a gold sun, as in the reference. Marcellus is the closest open typeface to the reference lettering; it is not the same font. |
| App icon, favicon, PWA icons, OG card | Generated from the emblem by `build.py`. |
| Mascot (`static/assets/brand/solar/mascot/`) | **Cut from the reference image**, idle pose only. See "Mascot" below. |
| Legacy scarab mark and North marks | Kept in `static/assets/brand/legacy/`. They are no longer referenced. |

| Titanium Slate | `#344258` | dark `--border` (at 70%) |

| Success / Warning / Error / Info | `#69BFA0` / `#E6A45B` / `#E07979` / `#7FAACB` | semantic |

**Gold is spent on one thing per view:** the primary action, where you are in
the navigation, the focus ring, or the number that matters. It is not used for
borders, headings or secondary buttons. The user's chat bubble is navy, not
gold.

**Light mode** uses Antique Gold rather than Solar Gold. Signal is also link
and number text, and Solar Gold on ivory is 1.7:1.

**Contrast:** `node scripts/brand/contrast.mjs src/lib/styles/app.css` prints
every text and control pair in both modes. All pass WCAG AA as of 2026-10-30
(text ≥ 4.5:1, control boundaries ≥ 3:1).

Data colours (the `sport-*` and `day-*` tokens, the body figure) are a separate
palette for legibility and were not changed. Strength and sleep keep the violet
they had when `agent` was violet.

## Typography

- **Marcellus** (`font-display`, iOS `Font.northDisplay`) is for brand moments
  only: the wordmark, the landing headline and section titles, the welcome,
  celebrations and recap headlines. It has one weight, so never bold it.
- **Geist** and **Geist Mono** handle everything else: navigation, controls,
  forms, data and long text.

## Logo use

| File | Use |
|---|---|
| `khepri-lockup-horizontal-{dark,light,mono}.svg` | Headers and documents. Minimum 96 px wide. |
| `khepri-lockup-vertical-{dark,light}.svg` | Covers and splash, with the motto. |
| `khepri-emblem-{dark,light}.svg` | The detailed emblem, 48 px and up. |
| `khepri-emblem-small{,-light}.svg` | The silhouette, 16–32 px: gold wings on dark, navy wings on ivory. |
| `khepri-emblem-mono.svg`, `khepri-wordmark-mono.svg` | One colour (`currentColor`). |
| `khepri-wordmark-{dark,light}.svg` | The name alone. |

- **Clear space:** at least the sphere's diameter on every side.
- **Minimum size:** 24 px for the emblem (use the small cut below 48 px) and
  96 px wide for a lockup.
- **Backgrounds:** use dark variants on Obsidian, Midnight or Armor, and light
  variants on Ivory or Stone. Don't place the emblem on photographs or gold.
- **Never** recolour the emblem, stretch it, add glow, or rotate it.

## Mascot

The mascot is a compact navy robotic scarab with gold trim, amber eyes, a
solar core in its chest and a gold orb on its head. Its personality is curious,
calm and supportive. `components/khepri/Mascot.svelte` (web) and `KhepriMascot`
(iOS) map states to poses. Motion is gentle hovering and a core glow that
animates only opacity. Both are static under reduced motion.

Only the **idle** pose exists. It was cut from the brand reference image with
macOS Vision subject lifting and is used as is; nothing was redrawn or
generated. Every other mood is the idle art moved and lit differently: tilt,
core glow, dimming. The distinct poses (thinking, success, sleeping and a
head-only avatar) are tracked in north-web-app issue #1. The idle cutout is
468×590 px, sharp up to about 200 CSS px; a professional illustration or Rive
rig would replace it.

## Motion

| Kind | Duration |
|---|---|
| Micro-interaction (press, toggle) | 120–180 ms |
| Component transition | 180–280 ms |
| View transition | 250–400 ms |
| Mascot idle | slow (6 s cycle), small amplitude |

The solar core, a sun inside a turning arc (`ui/spinner`), is the one loading
motif. Everything honours `prefers-reduced-motion` and iOS Reduce Motion.

## Rebuilding

```sh
python3 -m venv /tmp/brand-venv && /tmp/brand-venv/bin/pip install fonttools brotli
/tmp/brand-venv/bin/python scripts/brand/build.py
node scripts/brand/contrast.mjs src/lib/styles/app.css
# iOS: python3 scripts/sync-theme.py ../north-web-app/src/lib/styles/app.css (in north-ios-app/khepri)
```
